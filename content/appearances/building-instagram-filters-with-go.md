I gave a talk at the [London Gophers](https://gophers.london/) meetup about building image filters like those found in Instagram. This talk covers what I learnt while building a reference implementation of a simple rendering engine using pure Go, with no dependencies. I cover various kinds of lookup tables, storage formats and although useful... why it's probably a bad idea doing this in Go.

There is source code available at [github.com/wayneashleyberry/lut](https://github.com/wayneashleyberry/lut) if you'd like to try this out on your own images.
